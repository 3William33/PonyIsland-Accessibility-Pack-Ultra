# PonyIsland-Accessibility-Pack-Ultra

**简体中文** | [English](README_EN.md)

**《Pony Island》（小马岛）全游戏生存辅助 Mod**

一个给《小马岛》做的简单修改器，主要解决跳跃障碍、敌人攻击和部分战斗机制带来的反复死亡问题。

## 为什么做这个？

我很喜欢《Pony Island》的剧情、解谜和各种奇怪的小设计，但有些关卡的操作实在让我有点崩溃。我的妈呀这个耶稣先生让我非常难受啊。（）

尤其是某些需要反复躲避障碍的部分。我只是想继续看剧情、探索秘密、收集奖券，并不想在同一个地方死几十次。

所以我做了这个 Mod。

最开始，我主要是为了第三幕那关**不伤害耶稣、坚持到终点才能拿到的奖券**制作辅助：一边躲避障碍一边避免误伤真的很折磨人。后来我把它扩展成了全游戏通用的生存辅助。

目标很简单：**让我能够正常体验游戏，而不是被重复的操作关卡卡住。**

## 功能

| 按键 | 功能 | 默认状态 |
|---|---|---|
| **F8** | 全局生存辅助（主要用于耶稣奖券关） | OFF |
| **F9** | 24 张奖券解锁的隐藏战斗辅助 | OFF |

### F8 — 全局生存辅助

开启后，Mod 会尽可能阻止普通危险碰撞、敌人攻击和其他伤害机制导致的死亡或关卡重置。

可以正常进行移动、跳跃、射击、收集和解谜，不需要自动操作，也不会直接替玩家跳关。

**最初的用途：**第三幕的耶稣奖券挑战要求玩家在不伤害耶稣的情况下抵达终点。F8 可以帮助应对途中危险，但**不会自动替你完成奖券条件**；你仍需要自己操作，并注意不要攻击耶稣。

如今 F8 不再局限于特定的蝴蝶、门或某一个章节。

**注意：部分剧情需要玩家正常死亡或失败才能继续。遇到这种情况，请自己按 F8 关闭辅助，完成剧情后再重新开启。**

### F9 — 隐藏战斗辅助（轻微内容提示）

收集齐**全部 24 张奖券**后，游戏会解锁一场额外的隐藏 Boss 战。F9 专门为这场战斗提供辅助，**不是普通主线最终战的辅助功能**。这里不透露隐藏对手的身份或相关剧情。

F9 可以帮助处理这场战斗中的碰撞、瞄准和攻击问题，让对手通过游戏原本的伤害机制失去生命值。

F8 和 F9 可以分别开关，互不依赖。

两个功能在每次启动游戏时默认关闭，需要使用时再按对应按键。

## 安装方法

支持 Windows Steam 版《Pony Island》。

1. 下载本项目完整文件并解压。
2. 确保《Pony Island》已经完全退出。
3. 双击运行 `install.bat`。
4. 按照提示定位游戏安装目录。
5. 安装完成后，从 Steam 正常启动游戏。
6. 需要辅助时，按 **F8** 或 **F9**。

安装包已经包含插件 DLL 和相关运行组件，普通玩家不需要自行编译源码，也不需要管理员权限。

请保留下载文件原有的目录结构，不要只单独下载 `install.bat`。

## 关闭和卸载

**暂时关闭 Mod：**

完全退出游戏后，运行 `patch-off.bat`。需要重新启用时运行 `patch-on.bat`。

**卸载 Mod：**

完全退出游戏后，运行 `uninstall.bat`。

卸载时请注意已有的其他 BepInEx 插件，不要手动删除不属于本项目的文件。

### 卸载后游戏出现问题怎么办？

可以通过 Steam 验证游戏文件完整性：

**Steam → 库 → Pony Island → 右键属性 → 已安装文件 → 验证游戏文件完整性**

Steam 会检查并重新下载缺失或损坏的官方游戏文件。

注意：Steam 的文件验证不一定会清除第三方 Mod 添加的额外文件。如果问题依然存在，还需要检查游戏目录中的 BepInEx 和其他残留插件。

## 测试与说明

这个项目不是只停留在源码阶段的概念演示，我已经在自己的 Steam 游戏环境中进行了实机测试。

不过，《Pony Island》有大量特殊事件和非常规游戏机制，我不能保证所有关卡、所有剧情分支都不会发生兼容问题。

尤其需要注意：

- 剧情要求死亡时，请手动关闭 F8。
- 如果发现某个交互、奖券或剧情事件无法正常触发，先关闭辅助并尝试原版流程。
- 不建议在游戏运行过程中安装、卸载或替换插件。
- 本项目不提供自动跳关、自动修改存档或直接解锁 Steam 成就的功能。

更详细的历史测试记录可以查看 `docs/TEST-REPORT.md`。旧版本的测试结论不代表新版本的所有场景都已经覆盖。

## 源码

主要 C# 源码位于：

`src/AccessibilityPlugin.cs`

使用 BepInEx 和 Harmony 实现运行时补丁，不需要直接修改游戏原始程序集。

项目同时提供构建脚本，方便有需要的人自行研究或重新编译。
