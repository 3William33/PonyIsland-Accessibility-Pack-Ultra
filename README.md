# Pony Island Accessibility Pack

全游戏生存辅助 Mod，适用于 Steam 版《Pony Island》（Unity 2017.4.40f1，32 位）。

## 功能

### F8：全局生存辅助（默认关闭）

开启后，普通危险碰撞、敌人、弹幕和失败重置不会杀死或重置玩家；玩家仍可移动、跳跃、射击、解谜和交互。剧情需要真实死亡时，插件会自动关闭 F8，并放行原版剧情流程。

第二幕 Beelzebub 的真实死亡入口、第三幕蝴蝶/故障敌人、普通跳跃障碍及其他独立失败入口分别通过运行时 Hook 处理。飞刺仍会正常生成和飞行，命中玩家时只销毁该飞刺，不删除整套攻击机制。

### F9：终战辅助（默认关闭）

保留 v1.0 的终战行为：最终 Boss 三阶段辅助、自动瞄准和持续射击；Boss 血量仍由游戏原版激光逻辑扣减，目标为 40→0。

F8 与 F9 独立，按 F8/F9 切换。两个开关启动时均为 OFF。

## 安装

1. 完全退出游戏。
2. 将本仓库完整解压到任意位置。
3. 双击 `install.bat`，或运行 `install.bat "D:\\SteamLibrary\\steamapps\\common\\Pony Island"`。
4. 从 Steam 启动游戏，在游戏内按 F8 或 F9。

安装脚本只新增 BepInEx 和插件文件，不修改 176 个原始游戏文件。默认无需管理员权限。

## 卸载

完全退出游戏后运行 `uninstall.bat`。脚本只删除本插件 DLL、插件目录、v2 配置和安装标记，不删除 BepInEx 核心、其他插件、游戏文件、存档、注册表进度或 Steam 成就。

卸载后游戏不再加载本插件，即恢复为无本插件状态。

## 构建

源码位于 `src/AccessibilityPlugin.cs`。必须使用游戏自带的 Mono 2.x 程序集引用；运行 `src/build.bat` 可构建 DLL。普通用户不需要编译，发布包已包含可直接安装的 DLL。
